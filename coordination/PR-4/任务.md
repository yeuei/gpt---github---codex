## 已冻结行为（Frozen Behavior）

1. 用户从一个节点发起 action，但该节点 commit 只作为历史上下文锚点。
2. Dashboard/Trigger 不直接改 GitHub；GPT 收到 action 后重新读取 GitHub 当前 PR、HEAD 与任务真源。
3. 目标 PR 已 merged/closed 时，GPT 不得改写旧 PR 历史，应按 Coordinator 协议决定后续 PR 生命周期。
4. Dashboard action 提交不触发 `git fetch`；只有用户显式“从 GitHub 刷新”才同步 GitHub。
5. action 投递状态、Trigger event 审批状态、GitHub PR 状态不得互相推断。
6. “发送给 GPT”不授予 Codex shell/file approval，不自动 merge。
7. commit/PR/主要变更标题使用 `中文标题（English technical title）`。
