# 项目总览

> 本文件描述当前项目“是什么、为什么做、有哪些阶段、当前主线是什么”。
> 只保留当前有效版本；历史通过 Git 查看。

## 1. 项目名称

`gpt---github---codex`

## 2. 项目目标

当前尚未绑定具体业务/科研项目。

当前唯一已冻结目标是：

- 建立一个可供 ChatGPT ↔ GitHub ↔ Codex Agent 使用的标准交接仓库；
- 让任务、现实执行状态与 ChatGPT 决策分别通过标准文件表达；
- 以后所有项目事实以 GitHub 当前 HEAD 为准，而不是旧聊天记忆；
- 在用户提供首个正式项目目标后，再建立对应 PR 和项目技术规范。

## 3. 当前主线

```text
交接仓库初始化
  ↓
用户提供首个正式项目目标
  ↓
创建真实任务 PR
  ↓
实例化 coordination/PR-<N>/
  ↓
ChatGPT 规划 ↔ Agent 执行闭环
```

## 4. 当前阶段

- 当前阶段：`交接框架初始化完成，等待首个正式项目目标`
- 当前主要仓库：`yeuei/gpt---github---codex`
- 当前关键 PR：`无`

## 5. 当前不变量

- GitHub 当前 HEAD 是项目事实真源；
- `任务.md`、`agent汇报.md`、`chatgpt解惑.md` 三文件职责分离；
- 不预建虚构 PR 目录；
- 不创建版本号文档保存历史；
- 普通工程问题由 Agent 自行处理；
- 规划问题由 ChatGPT 处理；
- 改变核心项目口径的问题由用户决定。

## 6. 当前未决项

- 首个正式项目目标尚未提供；
- 因此项目技术实现、模型、数据、benchmark、运行环境等均尚未冻结。

## 7. 阅读路径

第一次进入项目：

1. 本文件；
2. `docs/技术规范.md`；
3. 当前 PR 的 `coordination/PR-<N>/任务.md`（若存在）；
4. 如果是 ChatGPT，再读 `agent汇报.md`；
5. 如果是 Agent，再读 `chatgpt解惑.md`。
