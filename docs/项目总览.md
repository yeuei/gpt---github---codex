# 项目总览

> 本文件描述当前项目“是什么、为什么做、有哪些阶段、当前主线是什么”。
> 只保留当前有效版本；历史通过 Git 查看。

## 1. 项目名称

`gpt---github---codex`

## 2. 项目目标

本仓库服务于一个本地常驻的 **GitHub ↔ ChatGPT Web ↔ Codex** 触发器。

已冻结目标：

- 监听实际交接仓库的 GitHub 分支更新，并以 Git trailer 的 origin/event id 路由事件；
- 从 Agent 更新唤醒固定的 remote ChatGPT Web Chat；从 ChatGPT 更新唤醒本地 Agent；
- 提供本地 Dashboard，支持全局暂停、两个方向独立开关、逐条人工审批及按 PR 的交接时间线；
- 第一版浏览器层使用 `open-browser-use`，但由确定性程序调用 CLI，不由 LLM 决定网页操作；
- 用本仓库进行真实分支/PR 的模拟交接，并据失败和回环改进三份基础协议仓库。

## 3. 当前主线

```text
Agent-origin commit
  ↓
本机 Trigger：解析 trailer、去重、记录
  ↓（人工批准，可单方向关闭）
ChatGPT Web 固定对话：重新读取 GitHub
  ↓
ChatGPT-origin commit
  ↓（人工批准，可单方向关闭）
本地 Codex Agent：fetch 后继续
```

## 5. 当前不变量

- GitHub 当前 HEAD 是项目事实真源；
- `任务.md`、`agent汇报.md`、`chatgpt解惑.md` 三文件职责分离；
- 不预建虚构 PR 目录；
- 不创建版本号文档保存历史；
- 普通工程问题由 Agent 自行处理；
- 规划问题由 ChatGPT 处理；
- 改变核心项目口径的问题由用户决定。
